## 📦 Notable Builds

### 🧠 AI Customer Intelligence System *(Digikala Jet)*
End-to-end ML pipeline: call center recordings → transcription → NLP sentiment analysis → RAG-based query layer → real-time dashboards. Processing **100K+ recordings**. Reduced support escalations **40%**.  
`n8n` `Python` `ClickHouse` `Vector Embeddings` `LLM` `Kubernetes`

---

### 📡 Zonerift — Intelligent VPN SaaS *(Founder, ongoing)*
Service-aware routing that automatically selects the optimal server per use case — streaming, gaming, crypto — without user intervention. **3,000+ users** across Iran, Russia, Eastern Europe. **1.5PB/month** traffic. **810% ROI**. Zero maintenance architecture.  
`Python` `WireGuard` `AWS` `Ansible` `PostgreSQL` `Redis` `Telegram Bot API`

---

### 📊 Self-Hosted Analytics Migration *(Digikala Jet)*
Migrated from Google Analytics to a fully self-hosted open-source stack after GA workspace deletion. Evaluated PostHog, Plausible, Openpanel, Rybbit on production. Forked PostHog, patched Next.js frontend and Python API for resource constraints. Final stack: **Rybbit on Kubernetes + ClickHouse**.  
`Kubernetes` `ClickHouse` `PostHog` `Rybbit` `Python` `Next.js`

---

### 🛣️ Toll Payment Feature *(Balad Maps — 4M DAU)*
0-to-1 product shipped in **2 weeks**: integrated government toll API + bank payment gateway + in-app checkout. Captured **2% of all national highway toll transactions** in 3 months. **21% CTR**, **6.2% conversion**.  
`Product Design` `API Integration` `Fake Door Testing` `Rapid Prototyping`
